## 📝 Sobre el Proyecto
Este es mi portafolio web personal, diseñado para centralizar y presentar mis proyectos, habilidades técnicas y desarrollo como estudiante de Ingeniería Informática radicado en Puerto Montt. El diseño está enfocado en el minimalismo, rendimiento y una experiencia de usuario fluida (UI/UX).

## 🛠️ Tecnologías y Prácticas Aplicadas
El proyecto fue construido desde cero sin el uso de frameworks pesados para garantizar tiempos de carga rápidos y demostrar dominio sobre los fundamentos web:

* **HTML5:** Estructura semántica clara para mejor accesibilidad y SEO.
* **CSS3:** 
  * Uso de variables nativas (Custom Properties) para consistencia de colores y fácil mantenimiento.
  * Implementación de **CSS Grid** y **Flexbox** para la alineación de elementos.
  * **Diseño Responsivo (Mobile First):** Interfaz adaptable a múltiples resoluciones y dispositivos móviles.
* **Arquitectura Limpia:** Separación estricta de estructura (HTML) y estilos (CSS).

## 📂 Estructura del Proyecto
- `index.html`: Estructura principal y contenido del portafolio.
- `style.css`: Hoja de estilos principal con variables de diseño.
- `perfil.jpg`: Fotografía de perfil optimizada.
